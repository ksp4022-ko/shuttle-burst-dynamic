# 首頁改版 — 斜擺實體羽球拍報名台

依附圖構圖重做首頁主視覺與操作區：粒子聚合後淡出，換成你附的實體白色球拍照片，拍柄左下、拍頭右上斜擺，資訊放在拍面內，已報/尚缺/後補維持附圖位置，季打／臨打三個彈窗改成「先選人再確認」。

## 主視覺

- 使用你上傳的球拍照片，去背成透明 PNG，存為專案素材（CDN 素材指標，不塞進程式碼庫）。
- 球拍以 CSS 旋轉成斜向：拍柄左下、拍頭右上，固定構圖，不直立、不置中垂直。真實比例（細中桿、拍面不放大）。
- 球拍後方 2–3 層陰影（金色微光 + 深色柔影 + 地面橢圓光暈），自然不壓過本體。
- 開場保留粒子聚合動畫；聚合完成後粒子在拍形位置閃一下光後淡出，實體球拍同時淡入並發光就位（尊重 prefers-reduced-motion，直接顯示成品）。

## 拍面資訊（拍頭內）

橢圓拍面內置一組資訊，層級由上到下：聚會名稱／日期（含星期）／費用／用球／名額。文字尺寸依拍面比例縮放，手機可讀，不外溢到拍面外圍。

## 已報 / 尚缺 / 後補

位於拍面下方、拍柄上方，一排三欄：

- 左：已報（螢光綠數字）
- 中：尚缺（金色數字，置中，半透明深色圓角底 + 柔陰影，視覺上壓在拍桿前方）
- 右：後補（灰白數字）

每欄下方細底線區分，字級大、一眼可辨。

## 操作區（拍柄作為中間分隔）

左右像從球拍延伸的輕量介面（僅細輪廓／微發光線條，無厚重卡片外框）：

- 左＝季打：「季打請假」「季打消假」兩顆金色描邊按鈕。
- 右＝臨打：姓名輸入欄、「我要報名」（螢光綠實心）、「取消報名」（螢光綠描邊）。

下方保留精簡名單條列。

## 三個彈窗（選人 → 確認）

統一的手機友善選人彈窗：大點擊區清單、單選高亮、底部「確認」按鈕（未選人時停用）。

- 季打請假：只列出目前未請假的季打人員。
- 季打消假：只列出已請假的季打人員。
- 臨打取消報名：只列出目前已報名的臨打人員（季打成員不列）。

確認後更新畫面狀態與已報/尚缺/後補數字。

## 技術做法

- 素材：以 imagegen 去背產生透明球拍 PNG，再用 `lovable-assets` 建立 `.asset.json` 指標後於元件 import 使用。
- 新元件 `src/components/RacketStage.tsx`：容器以 `aspect-ratio` + 百分比定位，把拍面資訊、三數值、操作區錨定在球拍圖上的相對座標，保證各手機寬度不跑位。
- 粒子：沿用 `MoleculeRacket`，新增聚合完成後的淡出（opacity 動畫），不動幾何檔案的資料結構。
- 狀態：首頁在 React state 內追蹤 `roster`（臨打已報名）與 `leaves`（已請假季打），皆由 `MEETUPS` mock 初始化；不改 `src/lib/mock-meetups.ts` 的型別與欄位。
- 新增 `SelectPersonDialog` 元件，三個流程共用，傳入名單與確認回呼。
- 顏色一律用 `src/styles.css` 既有語意 token（carbon / gold / neon），必要時只新增少量 token。
- 只改首頁相關檔案，不動路由結構、帳戶頁與後端。
