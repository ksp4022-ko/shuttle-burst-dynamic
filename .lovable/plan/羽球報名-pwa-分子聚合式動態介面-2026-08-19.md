# 羽球報名 PWA — 分子聚合式動態介面

以 Canvas 粒子 + GSAP 打造非方正的高級運動風報名頁：黑碳灰底、金屬金線條、螢光綠點綴。全部四階段一次做完，資料先用前端假資料（3 個聚會 + 名單），之後可無痛接後端。

## 畫面與流程

**階段 1 — 分子漂入 → 橫躺球拍成型**
- 進場：數百顆金／螢光綠幾何微粒由畫面左右兩側以流體亂流方式飄入中央，下方 UI 全部隱藏。
- 約 1.2 秒後（模擬載入完成）：粒子沿緩動曲線精準聚合到「橫躺羽球拍」的向量路徑上（拍框橢圓 + 拍線網格 + 拍桿 + 手把），成型瞬間有一次發光脈衝與細微震動。

**階段 2 — 選擇聚會**
- 球拍下方浮現單一螢光綠圓角膠囊按鈕「選擇聚會」（僅此一顆，無次要按鈕）。
- 點擊開啟磨砂玻璃彈窗，列出假聚會（日期／地點／名額）；確認後進入轉場。

**階段 3 — 球拍斜立 + 多聚會陰影**
- 按鈕淡出，球拍以 3D 透視旋轉＋縮放，緩慢有力地斜立（約 -18° 傾角）到畫面中央。
- 斜立完成後，主拍後方生成 2–4 個金色細線「球拍圖騰陰影」（空心線稿），各自以不同相位緩慢上下漂浮，代表其他可選聚會，可點擊切換。

**階段 4 — 功能狀態**
- 橢圓拍框內：聚會資訊以圓環狀排列環繞拍框（日期、人數上限、費用、用球），逐項依序浮現。
- 拍桿與手把流線區左右分流：
  - 左：「季打請假 / 消假」— 金色金屬環鎖智慧按鈕，超大字樣，需滑動／長按確認才切換狀態。
  - 右：「臨打報名」— 姓名輸入框 + 螢光綠「我要報名」智慧按鈕（idle → 送出中 → 成功 打勾變形）。
- 報名成功的名字以粒子形式飛入名單區（沿拍線排列的流線名單，非表格）。

## 技術做法

- 路由：改寫 `src/routes/index.tsx` 為此頁，並補上專屬 head() metadata。
- 動態：`gsap`（timeline / 3D transform / 智慧按鈕）＋ 自寫 Canvas 2D 粒子引擎（粒子數依裝置 dpr 與寬度自動降階，行動裝置約 350 顆、桌機 700 顆）。以 Canvas 2D 取代 Pixi.js：同樣達到數百顆粒子的流體聚合效果，但 bundle 更小、SSR 更安全。
- 球拍路徑：以 SVG path 定義球拍幾何，於瀏覽器端取樣為粒子目標座標；Canvas 元件走 `ClientOnly` + 動態 import，避免 SSR 取用 window。
- 設計 token：在 `src/styles.css` 新增碳灰／金屬金／螢光綠 oklch 語意色與碳纖維紋理、發光陰影；不寫死顏色 class。
- 狀態：單一 `stage` 狀態機（loading → assembled → picking → rising → active）驅動所有動態與 UI 顯隱。
- 假資料放 `src/lib/mock-meetups.ts`（聚會、名單、季打成員），介面設計成之後換成 Lovable Cloud 查詢即可。
- 尊重 `prefers-reduced-motion`：直接跳到成型後狀態。

## 不包含（之後可加）

資料庫、登入、真實報名寫入、PWA manifest / Service Worker（如需離線安裝再補）。
