# V11 Pending 清單

## 工作流程（同 V9，使用者定義）

1. **提出**：使用者提出問題並說「pending」，Claude 記進下方清單，自動編號（`V11-001`、`V11-002`…），狀態「待討論」，**不改程式**。
2. **討論**：Claude 提方案，和使用者來回調整，狀態「討論中」。
3. **確認**：使用者確認後，把定案寫進「方案」欄，狀態「已確認」。
4. **開工**：使用者說「開工」（可指定編號）才實作、驗證、推上 /v11test，狀態「完成」並寫 commit。
