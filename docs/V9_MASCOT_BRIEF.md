# V9 龍虎 Mascot 動圖製作說明 v1.1

用途：V9 首頁 Hero 右上角的龍虎吉祥物，依使用者「本場狀態」切換不同動圖。
目前是 CSS/SVG 暫代版（`src/components/v9/V9Mascot.tsx`，3 種表情），拿到動圖後替換。

使用方式：把本檔交給 ChatGPT（或其他生圖工具），先貼「三、共同風格」，再依序貼「四、各狀態指令」，
**全部狀態在同一個對話裡生成**，角色長相才會一致。

---

## 一、狀態清單

| # | 檔名 | 何時出現 | 動作設計 | 必要性 |
|---|---|---|---|---|

## 二、規格（每個狀態都一樣）

| 項目 | 規格 |
|---|---|
| 格式 | PNG 分格圖（sprite sheet），**透明背景** |
| 排列 | 橫排 6 格（6 個連續動作），**每格 480×360**，整張 **2880×360** |
| 對齊 | 6 格中角色位置、大小固定，只有動作改變 |
| 循環 | 第 6 格要能自然接回第 1 格（「操作成功」除外，只播一次） |
| 顯示尺寸 | 網頁上約 120×90 px，線條要粗、細節不要太多 |
| 背景 | 完全透明；網頁上背後已有黃色圓形，不要畫背景、地板、陰影 |
| 文字 | 圖裡不放任何文字或 logo（Zzz、號碼牌上的數字可以） |

## 三、共同風格（每次對話開頭先貼這段）

```
請幫我畫一組吉祥物角色的連續動作圖，用於手機網頁的羽球報名 App。

角色：一隻小綠龍和一隻小橘虎，是好朋友搭檔，頭身比約 1:1，圓滾滾的 Q 版可愛貼紙風格。
- 小綠龍：主色 #4CB782，肚子和口鼻淺綠 #BFE9CF，頭上兩支黃色小角 #FFE38A
- 小橘虎：主色 #F59A3C，臉頰和口鼻米白 #FFF6E5，額頭與臉側黑色虎紋，圓耳朵
- 兩隻臉頰都有淡粉紅腮紅
- 道具：白色羽球（紅色球頭 #E2554B）

風格要求：
- 粗黑色外框線 #1F1A17（約 3px 等寬），扁平色塊，不要漸層、不要寫實光影
- 可愛、活潑、簡潔，在小尺寸（約 120×90 px）仍看得清楚
- 透明背景，不要畫背景、地板或陰影
- 不要任何文字或 logo

輸出格式：
- 一張橫向 sprite sheet，6 格等寬排成一列，每格 480×360，整張 2880×360，PNG 透明背景
- 6 格是同一個循環動作的連續畫面，角色在每格的位置與大小固定
- 第 6 格要能順暢接回第 1 格（循環動畫）
- 每格之間留至少 40px 空白，角色、球拍、尾巴都不能超出自己的格子
- 每格 480×360 橫式，角色置中，上下不要留大片空白
- 角色本體要完全不透明，只有背景透明
```

## 四、各狀態指令（貼完共同風格後，一次貼一段）

### 1. 正取 → `mascot-confirmed.png`

```
狀態：正取（成功報名）。
動作：小綠龍和小橘虎開心地擊掌，一起小跳一下，羽球在兩人頭上彈起再落下。表情大笑、眼睛彎彎。
6 格：準備 → 舉手 → 擊掌 → 跳起最高點 → 落地 → 回到準備姿勢。
沿用上一張的角色設計。
```

### 2. 尚未報名 → `mascot-open.png`

```
狀態：尚未報名（邀請報名）。
動作：小綠龍朝畫面招手，小橘虎拿著羽球拍輕輕揮動，像在說「來打球！」。表情期待、眼睛發亮。
6 格：招手往左 → 中間 → 往右 → 中間，球拍同步小幅擺動，循環。
沿用上一張的角色設計。
```

### 3. 備取 → `mascot-waiting.png`

```
狀態：備取（排隊等待中）。
動作：小綠龍和小橘虎並排坐著，小綠龍手裡拿一張小號碼牌，兩人輕輕左右張望，有點緊張但可愛，偶爾眨眼。
6 格：看左 → 回正 → 看右 → 回正 → 眨眼 → 回正。
沿用上一張的角色設計。
```

### 4. 已請假 → `mascot-leave.png`

```
狀態：已請假（這場休息）。
動作：小綠龍和小橘虎靠在一起閉眼睡覺，羽球拍放在旁邊，頭上有「Z」字慢慢浮起變大再消失，身體隨呼吸輕微起伏。
6 格：呼吸起伏一個循環，Z 字依序往上飄。
沿用上一張的角色設計。
```

### 5. 未登入 → `mascot-guest.png`

```
狀態：未登入（歡迎訪客）。
動作：小綠龍和小橘虎一起對著畫面揮手打招呼，表情友善、好奇，頭微微歪一下。
6 格：揮手往外 → 中間 → 往內 → 中間，頭部同步小幅歪動，循環。
沿用上一張的角色設計。
```

### 6. 送出中（選做）→ `mascot-busy.png`

```
狀態：處理中（等待中動畫）。
動作：小綠龍和小橘虎各拿一支球拍，來回對打羽球，羽球在兩人之間飛過去再飛回來。
6 格：龍擊球 → 球往右飛 → 球到虎前 → 虎擊球 → 球往左飛 → 回到龍前。
沿用上一張的角色設計。
```

### 7. 操作成功（選做）→ `mascot-success.png`

```
狀態：操作成功（慶祝，只播一次，不需要循環）。
動作：小綠龍和小橘虎一起跳起來雙手高舉歡呼，周圍有小彩帶飛散。
6 格：蹲下 → 起跳 → 最高點雙手舉高、彩帶出現 → 下落 → 落地 → 站好微笑。
沿用上一張的角色設計。
```

## 五、驗收檢查（每張拿到後確認）

- [ ] 背景是真的透明（不是白底或棋盤格圖案）
- [ ] 整張 2880×360，6 格等寬，每格 480×360
- [ ] 6 格中龍虎位置、大小一致，不會忽大忽小或左右飄
- [ ] 第 6 格接回第 1 格不跳動（「操作成功」除外）
- [ ] 龍虎長相、配色跟前幾張一致
- [ ] 縮小到約 120×90 仍看得懂動作與表情
- [ ] 圖裡沒有多餘文字或 logo

不符合時可回覆 ChatGPT：
「請重新輸出，背景要透明，6 格每格 480×360 對齊排成一列，沿用同一組角色設計。」

## 六、交付後的接入方式（Claude 負責）

1. 檔案放到 `public/v9/mascot/`，檔名照「一、狀態清單」。
2. 轉成網頁動畫（CSS `steps()` 逐格播放或 animated WebP），每個檔案壓在約 150KB 以內，避免拖慢首屏。
3. 依「本場狀態」自動切換對應動圖；送出中、操作成功為短暫覆蓋。
4. iPhone 開啟「減少動態」時只顯示第 1 格靜態圖。
5. 圖片載入前先顯示現有 CSS 龍虎（`V9Mascot.tsx`），不會出現空白。
