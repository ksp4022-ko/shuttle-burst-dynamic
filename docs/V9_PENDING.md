# V9 Pending 清單

## 工作流程（使用者定義，2026-10-05）

1. **提出**：使用者提出問題，並說「pending」。
2. **記錄**：Claude 先把問題記進下方清單，自動編號（`V9-001`、`V9-002`…，接續最大編號，不重複使用），狀態設為「待討論」。這一步**不改任何程式**。
3. **討論**：Claude 提出方案（可以附預覽截圖，但不推上線），和使用者來回調整，狀態設為「討論中」。
4. **確認**：使用者確認方案後，Claude 把定案內容寫進該項的「方案」欄，狀態設為「已確認」。
5. **開工**：使用者說「開工」（可指定編號，例如「開工 V9-003」），Claude 才實作、驗證、推上線，狀態設為「完成」，並寫上 commit。

補充：
- 使用者沒說「pending」的一般要求，照平常流程處理，不必進清單。
- 一次可以 pending 多項；「開工」沒指定編號時，做所有「已確認」的項目。
- 編號前綴用 `V9-`，避免和 V8 tracker 的 `P-0xx` 混淆。
