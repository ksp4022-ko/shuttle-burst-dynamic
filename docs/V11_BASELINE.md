# V11 Baseline v0.1

Status: 初版 baseline（2026-10-20，D1–D12 已由使用者逐項確認）
Repo: `ksp4022-ko/shuttle-burst-dynamic`（frontend）／`ksp4022-ko/badminton-signup`（Worker，不改）

---

## 1. 定位

V11 是新的球員報名前台，功能與 V9 完全相同，只換呈現方式：

- **掉落舞台**：每場聚會是一張會掉落、堆疊、可拖曳甩出的貼紙（參考 artifact `6nSDoN2NpRQrZDpghWFPw9`「Market Drop Playground」）。
- **墨糰客服**：墨糰角色（參考 artifact `SgV2krQ6zcHissvmYokYJ5`「墨糰頭像機」）負責說話、引導操作、用表情反映狀態。

V11 只改前端呈現；不改 Worker、D1、帳務、報名規則、請假／回歸、候補順序、寬限期。

## 4. 墨糰對話（第一期，固定流程）

墨糰依「這場＋我的狀態」挑一句話與選項，例：

| 狀態 | 墨糰說 | 選項 |
|---|---|---|
| 未登入 | 先用 LINE 登入，我才知道你是誰喔 | LINE 登入／看名單 |
| 尚未報名、尚缺 N | 這場還缺 N 人，要來嗎？ | 我要報名／代報／看名單 |
| 尚未報名、額滿 | 已經額滿了，可以先排備取 | 排備取／看名單 |
| 正取 | 你已經在正取囉，第 N 位 | 我要請假（季打）／取消報名（臨打）／看名單 |
| 備取 | 你排備取第 N 位，有人請假就會遞補 | 取消報名／看名單 |
| 已請假 | 這場你請假了 | 我要消假／看名單 |
| 已開打／已結束 | 這場已經開打／結束了 | 看名單 |

常駐選項：我的帳單、加場規則（康軒）、常見問題（固定問答）、球員卡。
表情：開心（正取）、等候中（備取）、想睡（請假）、好奇（未報名）、讀取中／思考中（送出中）、驚訝／難過（錯誤）。

## 5. 元件規劃

- `src/components/v11/`：`V11App`、`V11Stage`（canvas＋Matter.js）、`V11StickerArt`（貼紙繪製）、`V11InfoCard`、`V11Mochi`（墨糰繪製，從 artifact 移植成 TS）、`V11MochiDialog`、`V11ListView`、`V11Styles`。
- `src/lib/v11-*`：路由、儲存鍵（`v11:`／`v11test:`）、對話規則、搖動偵測。
- V9 面板以 import 沿用，外觀用 V11 樣式覆蓋（D2）。
- 共用檔會動到：`__root.tsx`（路由）、`routeTree.gen.ts`、`v8-route-family`／`configuredFrontendVersion`（API 路由加 v11）、deploy workflow（加 v11 路徑）。回報需標「影響共用檔」並附 `/v8`、`/v9` regression。
- LINE 登入回程：Worker 目前接受 `/v8`、`/v9`、`/v9test`；`/v11test`、`/v11` 需要 Worker 放寬 returnTo（小改，需使用者同意，交 Codex 部署）。

## 6. 搖手機（D11）

- iPhone 需權限：使用者第一次按「搖一搖」按鈕時才呼叫 `DeviceMotionEvent.requestPermission()`；拒絕就只用按鈕，不再詢問。
- 只在舞台畫面、沒有開啟面板／資訊卡、沒有拖曳時偵測。
- 加速度超過門檻才算搖，觸發後冷卻約 1.5 秒，避免一直觸發。
- 開了「減少動態」或列表模式時不偵測。

## 7. 載入預算

不得讓 V9-065～070 的加速倒退：
- 首屏不含 Matter.js、墨糰動畫以外的大程式；Matter.js 首屏後才載入。
- 不載入中文網頁字型；Dela Gothic One 只用在英文標題，`display=swap`。
- 不預載右上龍虎狀態動圖（D8）。
- 目標：慢速 4G 冷開，讀取畫面出現時間不晚於 V9。
